### 🚀 Projeto em destaque

#### ⚽ Ranking de Futebol

Aplicação web para gerenciamento de jogadores, classificação e acompanhamento de estatísticas de partidas de futebol.

**Principais funcionalidades:**

- Sistema de pontuação por vitórias, gols e assistências
- Ranking atualizado automaticamente
- Estatísticas individuais dos jogadores
- Histórico de partidas e pontuações
- Painel administrativo para gerenciamento
- Atualizações em tempo real com Supabase
- Interface responsiva para dispositivos móveis

**Stack:** Next.js, TypeScript e Supabase.
